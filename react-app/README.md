# Botica Milagro

Plataforma web desarrollada para la gestión integral de una botica. **Permite administrar productos farmacéuticos, control de stock y precios, así como el registro de medicamentos y sus categorías**. El sistema ofrece una interfaz clara e intuitiva que facilita las operaciones diarias, optimiza el control de inventario y mejora la eficiencia en la atención al cliente.

## 🚀 Instalación y Ejecución

1. **Clona el repositorio:**

```bash
git clone https://github.com/anibalquis/botica-milagros-frontend.git
```

2. **Navega a la carpeta del proyecto:**

```bash
cd botica-milagros-frontend
```

3. **Acceder a la carpeta react-app:**

```bash
cd react-app
```

4. **Instala las dependencias:**

```bash
npm install
```

5. **Ejecuta el servidor de desarrollo:**

```bash
npm run dev
```
